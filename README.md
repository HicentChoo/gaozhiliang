# 高质量数据集管理服务平台

面向AI大模型的训练和应用的一站式数据加工平台。

## 功能特性

### 模块1：数据采集
- ✅ 支持结构化、非结构化、半结构化数据的采集
- ✅ 拖拉拽组件方式在画布上自由编排采集任务
- ✅ 数据源管理（维护采集的源和存储的源）
- ✅ 网络爬虫支持（可视化选择数据字段）
- ✅ 导入、填报等方式获取数据

### 模块2：数据集管理
- ✅ 创建数据集时选择数据来源（采集任务或导入文件）
- ✅ 支持不同场景的数据格式（System+Prompt+Response等）
- ✅ 文本数据集支持
- ✅ 查看数据集详情（表格形式展示）
- ✅ 数据集多版本管理（V1.0、V2.0等）
- ✅ 数据集内新增样本（不限制条数）

### 模块3：登录与用户、角色管理
- ✅ 用户登录功能
- ✅ 用户信息管理
- ✅ 角色管理

## 技术栈

- **前端框架**: React 19 + TypeScript
- **构建工具**: Vite
- **UI组件库**: Ant Design 6
- **路由**: React Router 7
- **状态管理**: Zustand
- **可视化流程**: React Flow
- **HTTP客户端**: Axios

## 使用说明

### 登录
- 测试账号：`admin` / `admin123`
- 登录后会自动跳转到数据采集页面

### 数据采集
1. 点击"新增数据源"创建数据源
2. 点击"创建采集任务"打开画布编辑器
3. 在画布上拖拽添加节点（数据源、处理器、存储）
4. 连接节点形成采集流程
5. 点击节点可配置节点参数

### 数据集管理
1. 点击"创建数据集"创建新数据集
2. 选择数据格式和来源
3. 在数据集详情中可以：
   - 查看数据集基本信息
   - 管理版本（创建V1.0、V2.0等）
   - 查看数据预览（如果是文件导入）
4. 点击"管理样本"可以添加、删除样本
